Actuarial nomenclature

Describe a life insurance projection model variable in plain English and get its standard name. For any market. The name is built by fixed rules from an open glossary. The name is never written by AI, and nothing you type leaves your browser.

Say what it is, whose share, on which basis, and when. If the description could mean two things, you will be asked which one. The tool never guesses.

Type a name to read it back in English and to check it against the rules.

Write a description on each line. To check names you already use, write the name, then a bar, tab or comma, then the description. The check flags vague descriptions, names that break the rules, names that do not match their description, and two different descriptions that end up with the same name.

Version , a draft for review. The standard, the glossary and this tool are open: github.com/proudchitts/actuarial-nomenclature. Definitions have not yet been reviewed by a second actuary. If you build or review models, suggest a term, correct a definition or report a wrong name.
